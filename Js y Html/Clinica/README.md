# App de turnos para clinica

Aplicacion web simple para registrar turnos de pacientes.

## Datos obligatorios para sacar turno

- Gmail
- Fecha de nacimiento
- Nombre
- Apellido
- DNI
- Razon de la consulta
- Fecha y hora del turno

## Requisitos

- Node.js 18 o superior

## Instalacion y uso

1. Instalar dependencias:

   ```bash
   npm install
   ```

2. Ejecutar la app:

   ```bash
   npm start
   ```

3. Abrir en el navegador:

   [http://localhost:3000](http://localhost:3000)

Los datos se guardan en `data/db.json`.
